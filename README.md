ARIA (Automated Regulatory Intelligence Agent) Shield Guard is the secure, high-performance frontend and backend orchestration layer for a 6-stage autonomous KYC compliance system. Designed for India's mid-market wealth management and PMS firms, this platform reduces manual onboarding from 2-4 weeks to under 10 minutes while enforcing strict PMLA, SEBI, and RBI regulatory guardrails.

---

## ✨ Core Features

*   **Real-Time Multi-Agent Telemetry:** Live visualization of the 6-stage AI reasoning pipeline (Intake, Guardian, Veritas, Compliance, Network Intelligence, Risk Report) via Supabase real-time subscriptions.
*   **Immutable Audit Trails:** Every AI decision, regulatory citation, and Human-in-the-Loop (HITL) approval is cryptographically logged in Supabase Postgres, ensuring 100% audit readiness for SEBI/RBI regulators.
*   **Adaptive Quality Recovery UI:** The frontend dynamically renders specific re-photograph guidance (e.g., "glare on bottom MRZ code") generated by the Guardian Agent, preventing hard-rejections and reducing client drop-off.
*   **Zero-Trust Security & Anti-Tipping:** Implements strict Row Level Security (RLS) policies. Critical flags like Suspicious Transaction Reports (STR) and PMLA Section 16 Anti-Tipping warnings are isolated and visible only to authorized compliance officers.
*   **Deterministic State Management:** Ensures the AI workflow cannot bypass mandatory human review. The UI enforces a strict "Review & Escalate/Approve" gateway before any state mutation occurs in the database.

## 🛠️ Tech Stack Breakdown

This repository is engineered for maximum performance, type safety, and enterprise security:

*   **Runtime Environment:** **Bun** 
    *   *Why:* Replaces Node.js/npm to provide ultra-fast dependency resolution, native TypeScript execution, and significantly reduced CI/CD pipeline times.
*   **Frontend Framework:** **React + Vite + TypeScript** 
    *   *Why:* Vite provides lightning-fast Hot Module Replacement (HMR). TypeScript ensures end-to-end type safety, eliminating runtime errors when handling complex nested JSON payloads from the AI agents.
*   **Styling:** **Tailwind CSS** 
    *   *Why:* Utility-first CSS allows for the rapid development of a highly readable, dark-mode optimized "glassmorphic" enterprise dashboard designed to reduce cognitive fatigue for compliance officers.
*   **Backend & Database:** **Supabase** 
    *   *Why:* Provides a production-ready Postgres database with built-in Auth and Row Level Security (RLS). Supabase Edge Functions act as the secure, low-latency bridge between the client UI and the Google Vertex AI Agent Platform.

## 🏗️ Architecture & Data Flow

1.  **Ingestion:** The compliance officer uploads client documents via the React frontend. Files are securely transmitted to **Supabase Storage** using signed URLs.
2.  **Trigger:** A database webhook or direct API call triggers a **Supabase Edge Function** (`aria-analyse`).
3.  **AI Orchestration:** The Edge Function securely authenticates and passes the payload to the **Google Vertex AI** multi-agent swarm (Gemini 2.5 Pro).
4.  **Processing:** The 6 specialist agents execute the compliance checks (Document Completeness -> Quality Recovery -> Cross-Doc Intelligence -> Regulatory Citations -> Crime Pattern Detection -> RAG Scoring).
5.  **Persistence:** The structured JSON output (Risk Score, Citations, STR flags) is written back to **Supabase Postgres**.
6.  **Real-Time Update:** The React UI, listening via Supabase Realtime, instantly updates the officer's Compliance Queue dashboard without requiring a page refresh.
